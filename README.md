# 키친프라이드 웹사이트

## 실행
`index.html`을 브라우저에서 열면 됩니다. 빌드 도구 없이 동작하는 정적 웹사이트입니다.

## 파일 구성
- `index.html`: 페이지의 섹션과 컴포넌트 구조
- `styles.css`: 색상, 레이아웃, 반응형 디자인
- `app.js`: 스크롤 노출 애니메이션
- `assets/`: 페이지에서 쓰는 로컬 이미지

## 이미지 출처
